# Halting drivers service

Its own folder, its own release. Everything that belongs only to this service lives here; what several services share
stays in `app/` (the kernel: api, auth, geo, billing, messaging, payments, customer gateway, dispatch core, components).

| Folder | What |
|---|---|
| `backend/modules/haltingdriverapp` | the partner (driver) app API, `/api/driver/*` |
| `backend/models` | the data models of its tables (booking, booking logs, driver requests, cancel duplicate, cancel charges, subscriptions, plans, ratings, city rate card, vehicle types, verification, driver earnings) - namespace `app\modules\admin\models` unchanged |
| `backend/dispatch` | booking expiry and booking admin actions (namespace `app\modules\dispatch\services` unchanged) |
| `backend/classmap.php` | generated by `php yii service/pack --service=haltingdriver`; tells the autoloader where these classes are |
| `partner-dashboard/controllers`, `views` | the admin screens of the service's data (shown over the shared admin views by the view theme), including bookings, earnings, invoices and the Cancellation Charges screen |
| `database/schema.sql` | structure of the service's own database (`rubia_haltingdriver`) |
| `customer-backend` | the customer-facing endpoints of this service: `/api/user/*` booking flow, `/api/booking/*`, `/api/wallet/*`, `/api/user-wallet/*` (module `haltingdriver-customer`) |
| `release/manifest.json` | what its release contains; `php yii service/release --service=haltingdriver` builds `release/dist/haltingdriver-<date>.zip` |

Not here yet: the partner app (mobile source) and the customer app are separate projects.
