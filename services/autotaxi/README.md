# Auto taxi service

Its own folder, its own release. The implementation of the partner (driver) API and the rider (customer) API is shared
by the car, auto and bike taxi services and lives in `libs/taxicore`; this folder holds what is only this service's.

| Folder | What |
|---|---|
| `backend/modules/autotaxidriver` | the partner API module of this service (`/api/auto/*`), a thin class over `libs/taxicore/backend/partner` that says which service it is (module 3) |
| `backend/modules/autotaxirider` | the rider (customer) API module (`/api/auto-user/*`), thin class over `libs/taxicore/backend/rider` |
| `backend/classmap.php` | generated by `php yii service/pack --service=autotaxi` |
| `database/schema.sql` | structure of the service's own database (`rubia_autotaxi`) |
| `release/manifest.json` | what its release contains; `php yii service/release --service=autotaxi` builds `release/dist/autotaxi-<date>.zip` |

Partner app: not built yet (only the Halting drivers service has one today).
