# taxicore (shared by car, auto and bike taxi)

The code the three taxi services share. There is no generic "taxi driver" or "taxi rider" service: each service has its own
module in `services/<service>/backend/modules` (thin classes that extend these and say which service they are).

| Folder | What |
|---|---|
| `backend/partner` | partner (driver) API: offers, accept / reject, ride progress, position (`TaxiController`, `TaxiOfferService`, `TaxiPresenceService`) |
| `backend/rider` | rider (customer) API: book, status, payment, rating (`TaxiUserController`) |
| `dashboard` | the taxi admin screens: ride requests, offers, earnings, payouts, ratings, commission, pincodes, vehicle types |
| `classmap.php` | generated by `php yii service/pack --lib=taxicore` |

Namespaces are unchanged (`app\modules\taxicore\partner`, `app\modules\admin\controllers\RideRequestController`, ...).
