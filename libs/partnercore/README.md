# partnercore (shared by every service)

Models and admin screens of the partner tables every service uses: `driver_details`, `driver_wallet`,
`driver_referral_earnings`, `driver_bank_details`, `driver_aadhar_card`, `driver_pan_cards`, `driving_license`,
`driver_emergency_contacts`.

| Folder | What |
|---|---|
| `models` | base models, models, queries and search models (namespace `app\modules\admin\models`, unchanged) |
| `dashboard` | the admin screens (controllers and views) of those tables |
| `classmap.php` | generated by `php yii service/pack --lib=partnercore` |

Each service database has its own copy of these tables (see `split/copy`); the code is shared, the data is not.
