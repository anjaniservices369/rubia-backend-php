# platform (the kernel every service and the user app share)

| Folder | What |
|---|---|
| `modules/api` | JSON API base (`ApiModule`, `BKController`), login-code handling |
| `modules/auth` | OTP, JWT, session lookup |
| `modules/geo` | service registry (`ServiceModules`), request scope, map designer, pincode areas, distance |
| `modules/billing` | invoices, tax reports, service report, customer-wallet switch |
| `modules/messaging` | push (OneSignal / Expo), SMS, WhatsApp |
| `modules/payments` | payment gateway clients |
| `modules/customerapi` | the customer-app API (profile, notify, authenticate; signed calls) |
| `modules/adminapi` | signed reporting for the super admin dashboard |
| `modules/dispatch`, `modules/filestorage` | dispatch module shell, media storage |
| `models` | users, auth, cities, states, services, web settings, banners, pages, coupons, notifications, ... (namespace `app\modules\admin\models`, unchanged) |
| `appmodels` | application models (`app\models`: `User`, forms, ...) |
| `classmap.php` | generated by `php yii service/pack --lib=platform` |
